# アクセシビリティ基礎の追加手順（FE-10, P2）

初版では最小限（セマンティックな HTML 要素、フォームのラベル付け）に留めている。
発展させる場合の指針。

## キーボードショートカット

- グローバルなキーボードショートカット（アプリ内 UI 操作）は `useEffect` +
  `window.addEventListener("keydown", ...)` ではなく、専用のライブラリ
  （例: `react-hotkeys-hook`）の導入を検討する。個別実装するとフォーカスされた
  input との競合や IME 変換中の誤発火が起きやすい
- OS レベルのグローバルショートカット（アプリが背面にあっても効く）は
  `docs/recipes/p2-app-features.md` の APP-10 を参照（別機能）

## フォーカス管理

- モーダル・ダイアログを追加する場合はフォーカストラップ（`focus-trap-react` 等）を使う
- ルート遷移時にフォーカスを `<main>` 等の主要要素に戻す（`src/routes/__root.tsx` の
  `Outlet` をラップする形で実装できる）

## チェックリスト

- [ ] インタラクティブ要素はすべてキーボードだけで操作できるか
- [ ] フォーカスリングを `outline: none` で消していないか（Tailwind の
      `focus-visible:` バリアントで意図的にスタイルする分には問題ない）
- [ ] 画像・アイコンボタンに `aria-label` があるか
- [ ] 色だけで情報を伝えていないか（エラー表示に記号やテキストも添える）
